# Hi, I'm Austin 👋

Full-stack development and robotics learner based in Nairobi, Kenya.
I enjoy building websites and exploring how software controls hardware.

## 🚀 Projects
- **[Joybasket](https://github.com/yskOsteen/Joybasket)**: Django watch-shop website (in progress). Contact form saved to a database, admin dashboard, and product catalogue coming next
- **[Ember & Bean](https://github.com/yskOsteen/ember-and-bean)**: responsive coffee shop website, deployed on Netlify. https://ember-beans.netlify.app
- **[Prime Haven](https://github.com/yskOsteen/PrimeHaven-)**: jewelry e-commerce website built with HTML, CSS and Bootstrap

## 📚 Currently learning
- Full-stack web development with Python and Django
- Databases and CRUD operations (models, migrations, Django admin)
- Robotics and embedded systems with Arduino

## 🛠️ What I've learned so far
- Building responsive websites with HTML, CSS and Bootstrap
- Setting up Django projects: apps, URL routing, views and templates
- Serving static files and adapting HTML templates to Django
- Creating forms with POST requests and CSRF protection
- Defining database models and saving form data with migrations
- Managing data through the Django admin (create, read, update, delete)
- Working in Python virtual environments
- Version control with Git and GitHub, and deploying sites on Netlify
